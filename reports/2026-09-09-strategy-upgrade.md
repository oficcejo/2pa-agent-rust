# 2PA / 遛狗策略改造

本地策略版本：`2026-09-v1`。这是执行规则改造，不是盈利回测结论。未部署至线上、未向交易所下单、未修改实盘环境配置。

## 策略拆分与兼容

| 选择 | 当前行为 |
|---|---|
| `2pa_trend` | 本周期和高周期 EMA 趋势同向，仅接受程序确认的二次入场或突破回踩 |
| `dog_reversion` | 大偏离后，二次极值测试、推动减速、收回/跌破 SMA14，并排除强逆向趋势 |
| `dog_trend` | SMA170 斜率、高周期同向、均线附近回踩和收盘突破确认；不使用回归距离门槛 |
| 旧 `2pa` | 映射到 `2pa_trend`；历史记录仍标识为旧版 |
| 旧 `dog_walking` | 映射到 `dog_reversion`；顺势回踩须显式选择 `dog_trend` |
| `adaptive` | 观察模式，不开新仓；有持仓仍可按共同规则管理 |
| `alpha_pilot` | 保留原生量化引擎，不参与这三个策略的选择 |

页面的分析选择、配置选择和历史归属已更新。新决策和交易审计包含策略 ID、版本及程序证据；旧审计无来源时显示“旧版未归属”，不补造策略来源。管理审计的策略 ID 表示当次管理规则，不代表追溯出的原始开仓来源。

## 程序硬条件

仅使用按时间倒序、连续、已收盘 K 线。指标缺失、预热不足、缺少有效高周期、未来或过期的高周期数据均拒绝新开仓。当前服务的高周期映射为 1/3/5/15m → 1h，30m/1h → 4h；其他周期没有结构化确认，三个策略将等待。

趋势定义：收盘位于 EMA20 同向一侧，EMA20 相对五根前的同向变化至少 0.1 ATR。SMA170 斜率使用 `(SMA170[0]-SMA170[5])/(5×ATR14[0])`。

- 共同确认：K1 已收盘、具有同向实体，且收盘突破 K2 高点（多）或低点（空）。
- 2PA 突破回踩：K3 收盘突破 K4–K10 极值，K2 回测该位 ±0.2 ATR，K1 确认。二次入场使用 K6–K1 的严格机械子集：回撤、第一次尝试、再次回撤、第二次收盘触发，并要求回撤在 EMA20 一 ATR 内。它不等同于所有人工 H2/L2 判读。
- 回归：K2–K6 至少一次反向偏离 2.5 ATR；K2 与 K4–K8 的极值差 ≤0.5 ATR；K2 到 K4 的位移不大于 K4 到 K6 的位移；K1 收回/跌破 SMA14。逆向 SMA170 每棒斜率不得强于 0.05 ATR，且高周期不得处于反向趋势。多空对称。
- 顺势遛狗：同向 SMA170 斜率至少每棒 0.02 ATR；K2 收盘位于均线 0.5 ATR 内、影线测试均线 ±0.2 ATR，K1 确认。

目标取前方最近已确认局部极值前 0.1 ATR。回归目标还受 SMA170 限制，以更近者为准。没有可验证目标的趋势单等待，不根据模型猜测投射远端目标。

## 定价与持仓

结构失效点取近三根极值；回归单覆盖近八根的两次测试。止损必须置于失效点外至少 0.2 ATR，总止损距离介于 `max(0.8 ATR, 0.3%×入场价)` 和 `3 ATR` 之间。入场距信号收盘不得超过 0.25 ATR。

扣除费用和滑点后的净盈亏比至少 1.5。胜出、止损两种退出分别计算开平仓价格对应的成本。合约每边手续费基线 0.05%，现货 0.1%，另预留每边滑点 0.02%。下单前在最新市价、价格取整后再次校验，风险定仓也包含滑点预留。未实现资金费预测。

程序不会为凑盈亏比扩宽或裁剪止损，不会为达到交易所最小手数上调仓位。只有 `take_profit_price` 实际执行，第二目标为 null；不实施分批退出。

所有风格共享硬条件。阶段一未放行、终止状态等待、模型方程拒绝、动作与订单类型矛盾均不得开仓。模型给出的胜率被清空，净盈亏比由程序覆盖。被拦截的提案保存在 `rejected_proposal`，理由保存在 `program_validation`，最终动作转为 WAIT 或 HOLD。

持仓止损只可收紧，移到盈利方向时必须覆盖成本；止盈不得逐棒推远。修改保护价在实际提交前按最新持仓及价格精度再次验证。未启用固定时间退出，亦未添加持续再平衡或分批平仓。
