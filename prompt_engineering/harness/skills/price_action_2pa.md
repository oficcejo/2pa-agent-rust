# Price Action (2PA) 策略技能

## 策略核心
基于 Al Brooks Price Action 价格行为学：
1. **趋势与急速 (Spike & Channel)**：顺大势交易，急速突破后等待第一次健康回踩进场，不在通道衰竭末端追单。
2. **二次入场机会 (Second Entry, H2/L2)**：在趋势方向出现两次试探反向失败后跟随入场，大幅提升胜率。
3. **震荡区间法则 (Trading Range)**：高抛低吸，中轴区域严禁顺势追单（铁丝网行情一律观望 WAIT）。
4. **主要趋势反转 (MTR)**：突破通道后出现强回抽测试极值点失败，形成更高低点 (HL) 或更低高点 (LH) 时介入。
